## Neon Strike Mobile (Shooter 2D)
Juego shooter 2D pensado para móvil, hecho con HTML5 Canvas + controles táctiles.

### Características
- Joystick táctil para movimiento.
- Botón de disparo continuo.
- Habilidad especial con cooldown.
- Oleadas progresivas de enemigos.
- Power-ups (`heal`, `rapid`, `weapon`, `shield`).
- Récord guardado en `localStorage`.
- También jugable con teclado en escritorio.

### Cómo ejecutar
```bash
python3 -m http.server 8000
```
Luego abre: `http://localhost:8000`
